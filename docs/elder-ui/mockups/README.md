## ImageGen 最终提示摘要

### 01 老人首页

以旧首页作为结构反例、旧通话截图作为小林身份参考；改成暖灰背景、白色内容面和 `#315E6B` 品牌色。仅保留问候、下一条提醒、今天另外两条提醒、最近通话/设置弱入口，以及底部「给小林打电话」唯一主按钮。禁止底部 TabBar、统计卡、兴趣标签、健康评分、Emoji、AI 标签和演示标签。

### 02 提醒来电

以旧通话截图锁定小林面孔、发型、米色衣服和家庭客厅。使用全屏真人视频构图，顶部显示「小林 / 来提醒您吃降压药」，底部仅保留对称的「拒绝 / 接听」。接听为蓝绿色，拒绝为红色语义；避让微信胶囊，不加入会议工具栏或 AI 标识。

### 03 通话中提醒成功

以上一张来电图锁定人物与环境。顶部显示小林、08:12 和「小林正在说话」；中下部显示紧凑的「已记下 / 明天 09:00 / 吃降压药」卡片与最近两轮字幕；底部仅保留静音、挂断、扬声器、字幕。确认卡和字幕不得遮挡面部。

### 04 通话结束

沿用首页的暖灰、白色、蓝绿色设计系统，不再大面积显示人物。页面只保留蓝绿色完成标记、「通话结束」「和小林聊了 8 分钟」、一张「刚才记下」卡片、弱入口「查看通话内容」和唯一主按钮「回到今天」。禁止情绪、健康和兴趣分析。

## 证据边界

- 样稿是目标视觉，不证明对应页面或自动来电已经实现。
- 自动到点提醒来电当前仍为系统待接入能力。
- 通话中提醒抽取与入库已有基础逻辑；「已记下」视觉反馈、失败反馈、静音/扬声器真实状态和字幕展开仍需开发。

- 样稿没有演示模式标识，符合已确认的小程序产品规则；内部验收仍需单独保留能力边界。
