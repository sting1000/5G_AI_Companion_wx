# 叮嘱小程序老人侧用户流程

> 状态：视觉重构冻结稿（2026-09-04）
> 适用范围：微信小程序老人侧；不包含子女侧。
> 关联文档：`SCREEN_SPECS.md`、`DESIGN_SYSTEM.md`。

## 1. 产品约束

- 产品名称为「叮嘱」，陪伴角色名为「小林」。
- 陪聊和设置提醒共用一次电话，不把老人带到单独的提醒表单。
- 老人日常界面只称「小林」，不显示「AI」「数字人」等标签。
- 小林使用真人感视频形象，但不得虚构真人公司、员工身份、联系方式或现实履历。
- 小程序没有面向用户的演示模式；模拟呼入、清空数据等测试能力不得出现在正式老人界面。
- 老人端不使用底部标签栏。首页是唯一根页面，详情页按需进入。
- 页面设计按老人独立日常使用为第一目标，同时保证投屏演示时仍然清楚。

## 2. 能力证据边界

| 标记 | 含义 |
| --- | --- |
| `已有` | 当前仓库已有可复用逻辑或页面能力 |
| `需开发` | 本轮视觉规格要求，但当前界面或行为尚未完整实现 |
| `系统待接入` | 目标产品流程；当前小程序只能通过页面或手动方式演示，不能声称系统级能力已经成立 |

- `已有`：实时语音通话、实时转写、完整提醒语句抽取、提醒本地入库、提醒回访话术、通话记录与摘要。
- `需开发`：老人侧新首页、首次称呼设置、权限引导、通话内提醒确认卡、静音/扬声器真实状态、字幕收起与展开、老人侧通话结束页。
- `系统待接入`：到点自动拉起的真实提醒视频来电。当前「提醒来电」样稿表达目标体验，不作为自动外呼已完成的证据。

## 3. 导航总览

```text
首次进入
  ├─ 设置称呼
  └─ 麦克风与通知说明
          ↓
老人首页「今天」
  ├─ 给小林打电话 ─→ 连接中 ─→ 通话中 ─→ 通话结束 ─→ 回到今天
  ├─ 下一条提醒 ───→ 提醒详情 ─→ 已完成 / 稍后提醒
  ├─ 查看全部 ─────→ 全部提醒 ─→ 提醒详情
  └─ 设置 ─────────→ 修改称呼 / 权限说明 / 关于叮嘱

系统待接入：到点提醒 ─→ 小林来电 ─→ 接听 ─→ 提醒回访 ─→ 通话结束
```

## F0 首次进入与称呼设置

**目标**：用最少输入完成个性化，让老人知道接下来为什么需要麦克风和通知权限。
**出口**：完成两步后进入 F1；权限拒绝也允许进入首页，但相关功能必须给出恢复路径。

### F0.1 设置称呼

1. 页面询问「希望小林怎么称呼您？」。
2. 老人可以输入称呼，或点击麦克风说出称呼。
3. 页面给出示例：`王阿姨`、`李叔叔`、`老张`。
4. 用户点击「就这样称呼我」。
5. 空值、单个符号、超过 10 个中文字符时原位提示，不离开页面。

**保存字段建议**：复用老人配置中的称呼字段；不要把展示样稿里的姓名写死到页面。

### F0.2 权限说明

1. 先在自有页面解释：麦克风用于和小林通话，通知用于到点提醒。
2. 用户主动点击后再调用微信权限请求，不在首屏直接连续弹系统授权框。
3. 麦克风拒绝：允许进入首页；电话按钮保持可点击，点击后说明原因并提供「去设置」。
4. 通知拒绝：允许通话和记录提醒，但必须说明「提醒不会通过通知出现」。

## F1 老人首页

**目标**：一屏回答两个问题——「今天要做什么」「怎样找小林」。
**入口**：首次设置完成、结束通话、从详情返回、小程序回到前台。
**出口**：F2 主动通话、F6 提醒详情、设置页。

### 正常路径

1. 顶部显示「今天」和用户设置的称呼，例如「早上好，王阿姨」。
2. 突出显示下一条提醒。
3. 最多显示今天其余 2 条提醒；更多内容使用「查看全部」。
4. 底部安全区固定唯一主按钮「给小林打电话」。
5. 主按钮辅助文案固定为「聊聊天，也可以请小林提醒您」。

### 首页状态

| 状态 | 界面表现 | 恢复动作 |
| --- | --- | --- |
| 首次加载 | 提醒卡片骨架；电话按钮可用 | 自动完成 |
| 今日有提醒 | 下一条提醒 + 最多 2 条其余提醒 | 点卡片看详情 |
| 今日无提醒 | 「今天没有要提醒的事」 | 给小林打电话 |
| 离线且有缓存 | 顶部轻提示「当前离线，显示上次内容」 | 重试 |
| 加载失败且无缓存 | 原因 + 「重新加载」 | 重试 |
| 麦克风未授权 | 电话按钮点击后说明权限用途 | 去设置 |
| 通知未授权 | 提醒区轻提示「通知还没有开启」 | 去设置 |

## F2 主动拨打小林

1. 用户点击「给小林打电话」。
2. 若麦克风未授权，进入权限恢复提示，不开始连接。
3. 页面进入全屏视频通话，依次显示「正在呼叫小林」和「正在接通」。
4. 接通后小林先问候，再进入自由陪聊。
5. 老人可以直接说提醒指令，不需要切换模式。

### 连接失败

- 网络断开：保留人物静态海报，显示「没有接通」和「重新呼叫」。
- 视频加载失败：退回同一人物静态海报，语音通话继续；不显示空白或黑屏。
- 语音服务失败：明确说明本次没有接通，不进入通话计时。

## F3 通话中陪聊并设置提醒

### F3.1 普通陪聊

1. 小林说话：顶部状态显示「小林正在说话」。
2. 老人说话：显示「正在听您说」。
3. 最近 1–2 句字幕位于人物下半部，不遮挡眼睛、嘴部和主要表情。
4. 点「字幕」打开完整字幕面板；关闭后回到最近字幕。

### F3.2 完整提醒指令

示例：老人说「提醒我明天早上九点吃药」。

1. 现有提醒抽取逻辑得到事项、时间、日期和置信度。
2. 页面先进入短暂的「正在记」状态，不提前显示成功。
3. 本地入库成功后，小林语音复述「好，我记上了，明早九点提醒您吃药」。
4. 同时显示确认卡：`已记下 / 明天 09:00 / 吃药`。
5. 确认卡保持 4–5 秒后淡出；用户可从字幕/提醒入口再次查看。

### F3.3 信息不完整

- 缺时间：小林只追问「您想让我几点提醒？」。
- 缺事项：小林只追问「到时候提醒您做什么？」。
- 在信息完整前不显示「已记下」。
- 未来计划但没有明确提醒意图，只生成待确认候选，不对老人承诺已设置成功。

### F3.4 保存失败

1. 确认卡显示「没有记成功」。
2. 小林说「刚才没有记成功，请您再说一次」。
3. 保留通话，不自动挂断。
4. 可重试；不得因为视觉动画完成而显示假成功。

## F4 到点提醒来电

> `系统待接入`：目标体验，不代表当前已经具备后台自动外呼。

1. 到提醒时间后出现小林真人感视频来电页。
2. 姓名为「小林」，来意为「来提醒您吃降压药」。
3. 用户点击「接听」进入通话；点击「拒绝」结束本次来电。
4. 接听后小林先复述事项并询问是否方便处理。
5. 老人确认完成后更新提醒状态；说「稍后」时再确认推迟时间。

## F5 通话控制与结束

### 通话控制

- 静音：切换后显示「麦克风已关闭」，再次点击恢复。
- 扬声器：切换后同时改变图标和文字，不只改变颜色。
- 字幕：展开完整字幕面板；再次点击收起。
- 挂断：立即结束本次通话，避免额外确认增加老人负担；误触防护由大间距和明确位置承担。

### 通话结束

1. 显示「通话结束」。
2. 显示本次时长，例如「和小林聊了 8 分钟」。
3. 若本次成功创建提醒，逐条显示「已记下」卡片。
4. 若没有创建提醒，不显示空提醒模块。
5. 主按钮「回到今天」返回首页并刷新提醒。

## F6 查看与处理提醒

1. 首页点击提醒卡进入详情。
2. 详情显示事项、日期、时间和重复规则。
3. 主操作「已完成」；次操作「稍后提醒」。
4. 删除入口位于更多菜单或页面底部，必须二次确认。
5. 老人端不使用左滑作为唯一删除或完成方式。

## F7 设置与恢复

设置页只保留：

- 小林怎么称呼我；
- 麦克风权限说明与恢复；
- 通知权限说明与恢复；
- 关于叮嘱；
- 隐私说明。

测试工具、清空数据、开发调试、模拟来电不得出现在正式老人侧设置页。

## 4. 交付验收

- 任意页面 3 秒内能看懂当前状态和唯一主操作。
- 所有可见图标都有真实动作；无动作的装饰图标不可伪装成按钮。
- 陪聊和提醒不出现模式切换。
- 提醒只有在入库成功后才能显示「已记下」。
- 页面不依赖底部 TabBar 完成核心闭环。
- 正文和控件避让微信右上角胶囊、状态栏与底部安全区。
- 目标来电流程在自动外呼未实现前，内部验收必须继续标记为「系统待接入」。
