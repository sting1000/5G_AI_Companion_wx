# 叮嘱小程序老人侧页面规格

> 状态：视觉重构冻结稿（2026-09-04）
> 本文定义页面内容、状态、动作和开发边界；流程见 `USER_FLOWS.md`，视觉 Token 见 `DESIGN_SYSTEM.md`。

## 0. 全局规则

### 页面状态

所有读取数据的页面必须覆盖：加载中、有内容、空、失败、离线。所有提交动作必须覆盖：初始、提交中、成功、失败。失败提示必须同时提供下一步动作。

### 导航

- 不使用底部 TabBar。
- 根页面为 S1 老人首页。
- 通话相关页面使用全屏覆盖；提醒和设置使用普通页面导航。
- 微信右上角胶囊区域不放置标题、状态或操作。
- 页面返回后保留原滚动位置；结束通话返回首页时刷新提醒列表。

### 文字与数据

- 样稿中的「王阿姨」「明天 09:00」「吃降压药」仅为虚构展示数据。
- 正式页面称呼读取首次设置结果，不硬编码。
- 日常页面只显示「小林」，不显示「AI 小林」。
- 不展示情绪评分、健康指数、风险值或子女看护指标。

## S0 首次设置

### S0A 设置称呼

**页面目标**：让老人完成唯一必要的个性化信息。
**标题**：「小林怎么称呼您？」
**说明**：「这样每次打电话，小林都能亲切地叫您。」

| 区块 | 规格 |
| --- | --- |
| 输入 | 单行文本，最多 10 个中文字符，placeholder「例如：王阿姨」 |
| 语音输入 | 输入框右侧麦克风按钮；识别后把结果写入输入框，仍可修改 |
| 示例 | 轻量建议词：王阿姨、李叔叔、老张；点击可填入 |
| 主按钮 | 「就这样称呼我」 |

**状态**：初始、语音聆听中、识别失败、校验失败、保存中。语音失败不阻断键盘输入。

### S0B 权限说明

**标题**：「让叮嘱更好地陪着您」

两张权限说明卡：

- 麦克风：「用来和小林通话」；按钮「允许使用麦克风」。
- 通知：「到时间提醒您」；按钮「允许发送通知」。

底部主按钮：「进入今天」。权限未完全开启时仍可进入，但按钮上方必须说明哪些能力会受影响。

## S1 老人首页「今天」

**对应样稿**：`mockups/01-elder-home.png`
**目标**：今天的事情和电话入口一眼可见。

### 结构顺序

1. 微信状态栏与胶囊安全区。
2. 导航标题「叮嘱」；右侧不再增加与胶囊竞争的按钮。
3. 问候：「早上好，王阿姨」；下方显示日期。
4. 「下一件事」重点提醒卡。
5. 「今天还有」列表，最多 2 条；超过时显示「查看全部」。
6. 页面内轻量入口：「最近通话」「设置」。
7. 底部固定电话按钮。

### 下一件事卡片

| 元素 | 示例 | 权重 |
| --- | --- | --- |
| 时间 | `09:00` | 页面内最大数字，等宽数字 |
| 事项 | `吃降压药` | 标题级 |
| 重复 | `每天` | 次级文字 |
| 状态 | `待提醒` + 时钟图标 | 蓝绿色轻底胶囊 |

整卡可点，最小高度 176rpx。禁止在卡片上加入情绪、健康评分或装饰性插图。

### 固定电话入口

- 主文案：「给小林打电话」。
- 辅助文案：「聊聊天，也可以请小林提醒您」。
- 左侧电话听筒图标，使用实心白色图标。
- 高度不小于 112rpx，底部使用安全区内边距。
- 点击后立刻进入 S3 的连接中状态。

### 状态变化

| 状态 | 主区域 |
| --- | --- |
| 今日有提醒 | 下一件事 + 最多 2 条其余事项 |
| 今日无提醒 | 时钟线性图标 +「今天没有要提醒的事」；电话按钮保持主焦点 |
| 加载中 | 卡片骨架，不让主按钮抖动 |
| 离线有缓存 | 顶部窄提示条，保留缓存内容 |
| 加载失败无缓存 | 原因、重试按钮；电话仍可进入但需独立检查网络 |

## S2 提醒来电

**对应样稿**：`mockups/02-reminder-incoming.png`
**能力状态**：目标产品设计；自动到点外呼为 `系统待接入`。

### 构图

- 小林真人感视频全屏铺满。
- 顶部使用透明到半透明的深色渐变，保证姓名和来意可读。
- 顶部中间依次显示「小林」「来提醒您吃降压药」。
- 底部使用较深渐变承载接听与拒绝按钮。
- 微信胶囊区域完整避让，不在其下方放置第三个操作。

### 操作

| 操作 | 样式 | 行为 |
| --- | --- | --- |
| 拒绝 | 白色半透明圆形 + 红色挂断图标 | 结束来电，返回首页 |
| 接听 | 蓝绿色实心圆形 + 白色接听图标 | 显示「正在接听」并进入 S3 |

按钮直径不小于 128rpx，图标不小于 52rpx。接听/拒绝不能使用仅滑动手势。

### 状态

- 来电中：人物保持轻微自然动作。
- 正在接听：两个按钮禁用，接听按钮内显示短进度。
- 视频失败：同一人物静态海报替代，不改变按钮位置。
- 接听失败：原位显示「没有接通」及「重新接听」。

## S3 通话中

**对应样稿**：`mockups/03-call-reminder-saved.png`
**目标**：人物关系第一，通话状态第二，控件第三。

### 页面结构

1. 全屏小林视频。
2. 顶部居中：`小林`、通话时长、当前语音状态。
3. 人物下半部：最近 1–2 句字幕。
4. 字幕上方或其下方：短暂的提醒确认卡。
5. 底部：静音、挂断、扬声器、字幕四个操作。

### 语音状态文案

| 内部状态 | 用户文案 | 视觉反馈 |
| --- | --- | --- |
| `connecting` | 正在呼叫小林 | 静态声波/轻进度 |
| `listening` | 正在听您说 | 蓝绿色呼吸点 |
| `userSpeaking` | 您正在说话 | 输入声波增强 |
| `assistantSpeaking` | 小林正在说话 | 小林视频切换 speaking 素材 |
| `muted` | 麦克风已关闭 | 麦克风斜线 + 实心选中底 |
| `reconnecting` | 网络不稳，正在重连 | 琥珀提示条；控件仍可用 |
| `failed` | 通话中断 | 静态海报 + 重新呼叫/结束 |

### 字幕

- 默认只显示最新 1–2 句；最大 4 行。
- 说话人标签使用「您」「小林」。
- 字幕背景必须足够不透明，不能依赖人物照片本身提供对比度。
- 点击「字幕」从底部打开完整字幕面板；面板可滚动并自动跟随最新内容。
- 字幕按钮有开启/关闭两种形态，不只改变颜色。

### 通话控制

- 排列：静音｜挂断｜扬声器｜字幕。
- 挂断尺寸最大，使用系统错误红；其余按钮为深色半透明或白色实底。
- 每个按钮同时包含图标和文字。
- 删除无真实动作的「全屏」「添加成员」。
- 静音与扬声器必须接入真实状态；未实现前不得展示为可点击控件。

### 通话内提醒确认卡（Q7 新功能）

建议页面状态：

```js
reminderFeedback: null || {
  state: 'saving' | 'saved' | 'failed',
  title: '吃降压药',
  scheduleText: '明天 09:00',
  reminderId: ''
}
```

状态契约：

| 状态 | 卡片标题 | 内容 | 自动关闭 |
| --- | --- | --- | --- |
| `saving` | 正在记下来 | 时间 + 事项 | 否 |
| `saved` | 已记下 | 时间 + 事项 + 对勾 | 4–5 秒 |
| `failed` | 没有记成功 | 「请再说一次」+ 重试提示 | 否 |

开发接点：

1. `_tryUpsertReminderCandidatesFromASRFinal` 目前调用 `store.upsertExtractedReminderCandidates`。
2. `store.upsertExtractedReminderCandidates` 已返回 `inserted/updated/skippedLowConfidence/insertedCandidates/updatedCandidates`。
3. 页面应基于返回结果区分 `saved`、待确认和未写入，不能只根据 ASR 文本推断成功。
4. 待确认候选不得显示「已记下」；由小林继续追问缺失字段。
5. 定时器在页面隐藏、卸载、挂断时清理，避免下一次通话闪现旧卡。

验收用例：

- 完整明确提醒 → 入库一次 → 显示 saved → 4–5 秒消失。
- 同一提醒重复表达 → 更新/去重后仍可显示 saved，但不新增重复记录。
- 无时间的未来计划 → 不显示 saved。
- 低置信或无提醒意图 → 不显示确认卡。
- 存储异常 → 显示 failed，且小林不能口头承诺已保存。

## S4 通话结束

**对应样稿**：`mockups/04-call-ended.png`

### 内容

- 成功图标：蓝绿色圆形对勾，不使用庆祝彩带。
- 标题：「通话结束」。
- 时长：「和小林聊了 8 分钟」。
- 本次有提醒时显示「刚才记下」卡片：`明天 09:00 / 吃降压药`。
- 主按钮：「回到今天」。
- 次入口：「查看通话内容」，仅在完整字幕/记录确实已保存时出现。

### 禁止内容

- 情绪评分、健康信号、兴趣标签。
- 面向子女的「重点关注」或「风险提示」。
- 不可验证的「已通知家人」「一定会提醒」承诺。

## S5 全部提醒与提醒详情

### 全部提醒

- 按「今天」「稍后」「已完成」分组，不使用复杂筛选 Tab。
- 提醒项显示时间、事项、重复规则和文字状态。
- 点击整项进入详情；左滑不能作为唯一操作方式。

### 提醒详情

- 页面标题：「提醒详情」。
- 主信息：事项和下一次提醒时间。
- 操作：「已完成」「稍后提醒」。
- 删除位于页面底部，使用文字按钮并二次确认。
- 通知未开启时显示明确提示和「去设置」。

## S6 设置

仅包含以下正式能力：

1. 小林怎么称呼我；
2. 麦克风权限；
3. 通知权限；
4. 关于叮嘱；
5. 隐私说明。

测试工具、开发 JSON、模拟来电和清空测试数据不能出现在正式页面。

## 1. 高保真样稿数据

4 张样稿使用同一组虚构数据，以验证连续性：

| 字段 | 样稿值 |
| --- | --- |
| 称呼 | 王阿姨（代表用户首次设置后的动态值） |
| 下一条提醒 | 今天 09:00 吃降压药 |
| 通话中新提醒 | 明天 09:00 吃降压药 |
| 来电事项 | 来提醒您吃降压药 |
| 通话时长 | 08:12；结束页简化为 8 分钟 |

## 2. 页面验收清单

- [ ] 首页只有一个高权重主操作。
- [ ] 所有文字与操作避开微信胶囊及安全区。
- [ ] 正常正文不小于 30rpx；辅助文字不小于 26rpx。
- [ ] 点击热区不小于 88×88rpx。
- [ ] 图标、文字和状态三者语义一致。
- [ ] 视频失败时仍有同一人物静态海报。
- [ ] 通话控制都有真实状态和事件绑定。
- [ ] 提醒写入成功前不出现「已记下」。
- [ ] 自动提醒来电在系统能力未接入前不作为完成项验收。
