# 叮嘱小程序老人侧设计系统

> 状态：视觉重构冻结稿（2026-09-04）
> 视觉母版：当前 `5G_AI_Companion_iOS_Demo` 的实际 Asset Catalog 与 SwiftUI 组件；不是旧版小程序珊瑚红界面的延伸。

## 1. 视觉定位

**关键词**：温暖、克制、可信、生活化、成熟消费级。
**记忆点**：家庭相册式的小林真人画面 + 一条克制的蓝绿色声波。
**避免**：科技舱、发光球、紫色渐变、透明卡片堆叠、到处闪动的声波、儿童化插画、Emoji 功能图标。

产品应像一项长期可靠的家庭生活服务，而不是一张展示 AI 能力的概念图。

## 2. 设计原则

1. **人物关系优先于技术表达**：只称「小林」，不在日常页面反复强调技术身份。
2. **一屏一个主任务**：老人首页只有「给小林打电话」一个主操作。
3. **适老不等于粗糙大字**：正常字号、清晰层级、充足留白、大触控区和少量信息共同保证可用性。
4. **成功必须来自真实结果**：提醒入库成功前不能显示「已记下」。
5. **系统状态说人话**：用「正在听您说」「没有接通」，不用协议、ASR、LLM 等内部词。
6. **图标只辅助文字**：关键动作同时显示图标和中文，不让老人猜图标。

### 颜色限制

- 珊瑚红 `#FF6A4F` 不再作为品牌主色。
- 红色只用于挂断、错误和删除确认。
- 提醒未确认、网络重连使用琥珀色，不把老人行为表现成危险。
- 状态必须同时有图标或文字，不能只靠颜色。

## 4. 字体

微信小程序使用系统中文字体栈，保持与 iOS Demo 的平台一致性和老人端可读性：

```css
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC", "Helvetica Neue", sans-serif;
```

| Token | 大小 | 行高 | 字重 | 用途 |
| --- | --- | --- | --- | --- |
| `display` | 52rpx | 68rpx | 700 | 首页问候、结束页标题 |
| `title-1` | 44rpx | 58rpx | 700 | 页面主标题 |
| `title-2` | 36rpx | 48rpx | 600 | 区块与重点事项 |
| `body-lg` | 34rpx | 50rpx | 500 | 通话字幕、主要说明 |
| `body` | 30rpx | 44rpx | 400 | 正文与列表 |
| `label` | 28rpx | 40rpx | 600 | 按钮、状态 |
| `caption` | 26rpx | 36rpx | 400 | 日期、辅助说明 |

- 时间与计时使用等宽数字特征，避免数字变化造成跳动。
- 正文不使用全大写英文标题，例如不再出现 `AI SUMMARY`。
- 最多使用 700、600、500、400 四档字重。

## 5. 间距、尺寸与安全区

### 5.1 8rpx 基础标尺

| Token | 值 | 用途 |
| --- | --- | --- |
| `space-1` | 8rpx | 图标内部、紧邻信息 |
| `space-2` | 16rpx | 同组元素 |
| `space-3` | 24rpx | 列表行内部 |
| `space-4` | 32rpx | 页面水平边距、卡片内边距 |
| `space-5` | 48rpx | 区块间距 |
| `space-6` | 64rpx | 首屏大留白 |

### 5.2 圆角

| Token | 值 | 用途 |
| --- | --- | --- |
| `radius-sm` | 20rpx | 提示条、小控件 |
| `radius-card` | 36rpx | 普通卡片，对应 iOS 18pt |
| `radius-hero` | 48rpx | 重点提醒与结果卡，对应 iOS 24pt |
| `radius-pill` | 999rpx | 主按钮、状态胶囊 |

### 5.3 触控

- 所有点击热区不小于 88×88rpx。
- 主电话按钮高度不小于 112rpx。
- 来电接听/拒绝圆形按钮直径不小于 128rpx。
- 通话控制图标本体 48rpx，点击圆形直径 104–112rpx。

### 5.4 微信安全区

- 使用 `wx.getMenuButtonBoundingClientRect()` 或统一自定义导航组件计算顶部胶囊位置。
- 标题内容顶部不得低于胶囊 `bottom + 16rpx`。
- 右上角胶囊水平范围内不得放置自定义操作。
- 底部固定操作使用 `env(safe-area-inset-bottom)`；滚动内容预留按钮高度，避免被遮挡。

## 6. 空间与卡片

- 页面左右边距统一 32rpx。
- 首屏最多一个大卡片，其他内容优先使用分组列表和分隔线。
- 普通卡片只使用 1px 低对比描边和极轻阴影：`0 12rpx 36rpx rgba(24,40,43,.06)`。
- 不使用每块内容都悬浮的「白色卡片海」。
- 下一条提醒可以使用 `color-brand-tint` 作为色面，其余提醒使用白底列表。
- 主页不展示累计次数、累计时长、兴趣标签和健康信号。

## 7. 组件规范

### C1 主电话按钮

- 蓝绿色实心胶囊，白色电话听筒图标。
- 两行结构：主文案「给小林打电话」；辅助文案位于按钮上方的独立说明区，不塞进按钮内部。
- 按下态缩放不低于 0.98，持续 160ms；不要使用发光或弹跳。

### C2 下一条提醒卡

- 时间是第一视觉锚点，事项是第二视觉锚点。
- 状态使用时钟图标 +「待提醒」。
- 整卡可点击；右侧箭头仅作为方向提示，不作为独立点击目标。

### C3 提醒确认卡

- 深色半透明但对比稳定，位于字幕附近。
- 成功态：实心对勾、标题「已记下」、时间、事项。
- 失败态：错误图标、标题「没有记成功」、动作「请再说一次」。
- 进入/退出仅使用 180–240ms 的透明度与轻微位移，不旋转、不弹跳。

### C4 最近字幕

- 最多 2 个说话轮次、4 行文字。
- 字号使用 `body-lg`，行高不小于 1.45。
- 背景 `color-call-overlay`，圆角 32rpx。
- 不遮挡小林眼睛、嘴部和主要手势区域。

### C5 通话控制

- 静音、扬声器、字幕使用统一圆形容器。
- 挂断使用更大的红色圆形，并与其他控件保持至少 40rpx 间距。
- 开启状态同时改变图标形态、容器明暗和文字。
- 图标下面始终有中文标签。

### C6 来电按钮

- 接听：`color-brand`；拒绝：白色半透明容器 + `color-error` 图标。
- 两个按钮保持对称，不增加消息、提醒稍后等次要动作。

### C7 通话结束结果

- 页面以文字和少量卡片为主，不继续使用人物全屏视频。
- 一个蓝绿色对勾、通话时长、可选的「刚才记下」卡片。
- 唯一主按钮「回到今天」。

## 8. 图标系统

### 8.1 造型

- 24×24px 矢量网格；视觉线宽 1.8–2px。
- 圆端点、圆连接、统一 2px 安全边距。
- 默认使用线性图标；主操作和强状态允许实心版本。
- 禁止 Emoji、文字字符充当功能图标，也不直接导出 Apple SF Symbols 作为小程序素材。
- 小程序内页使用 SVG；如平台组件要求 PNG，则从同一 SVG 母版按 1×/2×/3×导出。

### 8.2 第一批图标清单

| 分组 | 图标 |
| --- | --- |
| 核心 | 电话、接听、挂断、麦克风、麦克风关闭、扬声器、扬声器关闭、字幕、字幕关闭 |
| 提醒 | 时钟、提醒铃、完成、稍后、重复、日历 |
| 通用 | 返回、进入、设置、编辑、删除、警告、重试、隐私 |

### 8.3 状态

每个交互图标必须定义：默认、按下、选中、禁用。选中态不能只改变颜色；例如麦克风关闭必须更换为带斜线的图形。

## 9. 人物视频与图片

- 小林在4张样稿中必须保持同一面孔、发型、年龄感和服装气质。
- 视频画面使用自然室内光、家庭客厅、真实皮肤纹理和轻微自然动作。
- 来电页与通话页全屏使用人物；首页只用小面积头像或横向人物裁切。
- 人物视线接近镜头，表情亲切但不过度微笑。
- 顶部与底部允许加渐变遮罩；人物主体本身不能被大面积半透明卡片覆盖。
- 视频失败必须回退到同一人物静态海报。

## 10. 动效

| 动效 | 时长 | 规则 |
| --- | --- | --- |
| 按钮按下 | 160ms | 轻微缩放与透明度 |
| 页面进入 | 220ms | 淡入 + 8rpx 上移 |
| 提醒确认卡 | 220ms | 淡入 + 12rpx 上移；4–5 秒后淡出 |
| 状态点 | 1.6s | 仅在正在听时缓慢呼吸 |
| 声波 | 跟随语音 | 无真实音量时使用克制循环，不伪装精确音量 |

所有动效必须可中断，不得延迟接听、挂断或权限操作。

## 11. Mobbin 参考与提取原则

- [Apple Reminders 首页](https://mobbin.com/screens/84be367a-1f4e-48ac-8740-541510d01dad)：借鉴清晰分组、时间优先和系统级图标秩序；不照搬彩色分类卡。
- [Messages 来电页](https://mobbin.com/screens/14202221-b6bd-49f8-bed3-14a8f4bf985a)：借鉴来电姓名、来意与接听/拒绝的单一层级。
- [Bolt 通话页](https://mobbin.com/screens/cd2f9b27-1eca-4e4d-a12d-0259e9c25189)：借鉴底部通话控制的清楚标签和稳定位置。
- [Craft 提醒操作](https://mobbin.com/screens/6724ed7d-c631-4b7e-a26f-a44f83b6bc12)：借鉴完成、改期、删除的动作优先级。

不采用：儿童化角色插画、二次元沉浸画面、视频会议式多功能控制栏、纯装饰性的 AI 发光效果。

## 12. 样稿一致性检查

- [ ] 4张图使用同一套颜色、字号、圆角和图标语言。
- [ ] 小林在来电与通话样稿中为同一人物。
- [ ] 首页和结束页的称呼为动态数据示例，不暗示写死。
- [ ] 右上角微信胶囊没有遮挡任何自定义元素。
- [ ] 通话页没有「AI」标签、添加成员或伪功能图标。
- [ ] 任何「已记下」都同时展示明确时间和事项。
- [ ] 红色只出现在挂断等明确语义上。
- [ ] 样稿没有演示模式或体验来电标识。
